# 참고 계정 분석

## @economy.notes (따라갈 방향)
- 한 장짜리 인포그래픽. 상단 큰 헤드라인 + 부제 캡슐, "지금까지 vs 앞으로" 비교 패널, 번호 매긴 핵심 6개, 찬반 입장, 하단 질문 배너.
- 수치형 게시물은 꺾은선 차트 + 우측 변동폭 표 + 하단 핵심 포인트 3개 카드.
- 캡션: 이모지 소제목, 수치 나열, 핵심 포인트 3개, 끝에 자기 계정 멘션 반복, 해시태그 5개 내외.
- 약점: 캡션에 `**` 마크다운이 그대로 노출됨 (AI 생성 결과를 그대로 붙여 넣은 흔적). 실존 인물 사진 사용.

## @lime.now (하지 않을 방향)
- 연예·정치 가십. 인물 실사 사진 + 자극적 자막("ㄷㄷ", "🚨").
- 발언을 맥락 없이 잘라 해석을 붙이는 경우가 있어 법적 위험이 크다.
- 팔로워 2.7만, 게시물 1,233개. 수익 구조는 광고·협찬 위주라 제휴 링크와 맞지 않음.
